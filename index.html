The Crow
Objective 1 · Crows

Do crows follow restaurants?

Crows are urban generalists. Their sighting frequency barely shifts between SF's quietest residential neighborhoods and its densest commercial corridors, 37% to 35%. They don't need Clement Street. They just don't avoid it.

That's because food businesses create exactly the infrastructure crows exploit: dumpsters, outdoor dining scraps, bin collection days. The same density that drives jays out functions as a food subsidy for crows. They are commensal.

Jays are the opposite. Their frequency drops 2.5x in high-commercial neighborhoods. Same family, opposite strategy. That contrast is what this chapter is about.

Objective 2 · Parrots

The documentary made Telegraph Hill their address. The data disagreed.

Fort Mason peaked at 92 sightings in 2022. Telegraph Hill peaked at 30 the same year. The crossover happened around 2013 and Fort Mason has led ever since.

By 2025 the Presidio peaked at 68 sightings. The colony's center of mass has shifted west. The Presidio is now the fastest-growing site.

Methodology

The primary dataset is the eBird Basic Dataset for San Francisco County (US-CA-075), downloaded from the Cornell Lab of Ornithology. The raw file contained 5,054,584 rows and was cleaned to 621,286 approved, deduplicated records covering 757 species from 1884 to 2026. The cleaning pipeline was written in Python using pandas with assistance from Claude (Anthropic). Cleaning steps included filtering to APPROVED = 1, deduplicating shared checklists using GROUP IDENTIFIER, parsing OBSERVATION DATE into year and month fields, dropping rows with missing coordinates, and flagging exotic species via EXOTIC CODE. All bird frequency metrics are normalized by checklist effort: frequency = sighting checklists divided by total complete checklists (ALL SPECIES REPORTED = 1) per neighborhood.

One secondary dataset from DataSF provided urban infrastructure context. The Registered Businesses dataset was filtered to active food establishments using NAICS code (Food Services) and LIC code keywords (restaurant, bar, bakery, caterer, and related terms). Because the business file uses different neighborhood boundary names than the eBird analysis neighborhoods, a three-pass pipeline with manual name mapping was required to fill all 111 neighborhoods. Claude assisted in writing and debugging all three pipeline scripts.

The parrot pipeline extracted 2,350 Red-masked Parakeet sightings from the cleaned eBird CSV and aggregated them by colony location and year. The raptor pipeline computed monthly sighting totals and species-level monthly distributions for four species. Both scripts were written with Claude's assistance. All heavy computation was done offline. The browser loads pre-aggregated JSON files under 300kb total.

All visualizations are built in D3.js v7 and embedded as iframe elements so each chart can be developed and tested independently. The animated parrot bubble map uses Leaflet.js for the basemap with a D3 SVG overlay. Scroll behavior is managed by Scrollama.js. Synchronized hover between the radial bar chart and small multiples uses the postMessage API to pass month index values between iframes through the parent window.
